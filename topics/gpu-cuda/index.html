GPU Programming with CUDA

目标：在一块真正的 NVIDIA GPU 上写出、测量并剖析 CUDA 内核，从 warp 一路理解到驱动；同一套思路在这台 Mac 上用 Metal 再做一遍。Mac 没有 NVIDIA GPU，所以 CUDA 实验在云端 GPU 上做（先用免费的 Colab T4，剖析阶段再租一台），每一页都配一个在本机运行的 Metal 对照实验。

Goal: write, measure and profile CUDA kernels on a real NVIDIA GPU and understand the GPU from the warp up to the driver, then do the same in Metal on this Mac. The Mac has no NVIDIA GPU, so the CUDA labs run on a cloud GPU (a free Colab T4 first, a rented machine for the profiling phases), and every page carries a Metal twin that runs here.

读者画像：做过 Parallel Programming（线程、内存模型、SIMD、roofline）和 Kernel Engineering（驱动、DMA、缺页）。每个 phase 大约 1–2 周（每天 1–2 小时）。CUDA 实验以 sm_75（T4）为最低目标；Metal 对照实验用 Swift 在运行时编译内核，只需 Command Line Tools。先看「实验环境」。
Reader: has done Parallel Programming (threads, memory models, SIMD, the roofline) and Kernel Engineering (drivers, DMA, page faults). Each phase is about 1–2 weeks at 1–2 hours a day. The CUDA labs target sm_75 (a T4) as the minimum; the Metal twins compile their kernels at runtime from Swift and need only the Command Line Tools. Start with the lab environment page.
