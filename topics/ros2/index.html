Learning Garden ROS 2

ROS 2

目标：把机器人中间件学到能独立搭一套小型机器人软件栈——从第一个 node，到一台在 Gazebo 里建图、导航的仿真机器人——并且始终看得见它脚下的操作系统：线程、调度、socket、驱动。版本钉在 ROS 2 Jazzy Jalisco（LTS，2024-05 至 2029-05）+ Gazebo Harmonic；把命令里的发行版名换成 lyrical 就是最新的 LTS。

Goal: learn robot middleware well enough to build a small robot stack on your own, from a first node to a simulated robot that maps and navigates in Gazebo, while always keeping the operating system beneath it in view: threads, scheduling, sockets, drivers. Pinned to ROS 2 Jazzy Jalisco (LTS, May 2024 to May 2029) with Gazebo Harmonic; swap the distribution name in the commands for lyrical and you are on the newest LTS.

读者画像：会 Python、看得懂 C++、用得惯 Linux 命令行；做过或正在做 Kernel Engineering。每个 phase 大约 1–2 周（每天 1–2 小时）。所有实验在 Apple Silicon Mac 上的 Linux 客体机里做，先看「实验环境」。
Reader: knows Python, can read C++, is at home on the Linux command line; has done or is doing Kernel Engineering. Each phase is about 1–2 weeks at 1–2 hours a day. Every lab runs in a Linux guest on an Apple Silicon Mac; start with the lab environment page.
