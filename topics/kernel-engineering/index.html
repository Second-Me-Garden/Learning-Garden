Learning Garden Kernel Engineering

Kernel Engineering目标：Apple 的 kernel engineer 岗位。九个阶段。Goal: a kernel engineer role at Apple. Nine phases.

目标：具备申请 Apple kernel engineer 岗位所需的内核功底。路线：先用 Linux 把内核基础打牢（公开资料最丰富、能在 QEMU 里随便拆），每一阶段同时对照 XNU（Mach + BSD + IOKit，Apple 的内核不是 Linux），最后一阶段切换到 Apple 路线。

Goal: the kernel fundamentals an Apple kernel-engineer application needs. Route: build the basics on Linux first (the richest public material, and you can take it apart freely in QEMU), compare every phase with XNU (Mach + BSD + IOKit — Apple's kernel is not Linux), and switch to the Apple track in the last phase.

读者画像：会 C、知道进程/虚拟内存/系统调用是什么，但没有读过内核源码。每个 phase 大约 1–2 周（每天 1–2 小时）。
Reader: knows C and what processes, virtual memory and system calls are, but has not read kernel source. Each phase is about 1–2 weeks at 1–2 hours a day.

实验环境

所有实验都在客体机里做：QEMU 里的 Linux arm64 做内核实验，容器做构建，macOS 客体 VM 做 XNU / kext / 关 SIP 的实验。宿主机永远不动。先读 实验环境：VM、容器、快照，再开始 Phase 0。

Lab environment

Every lab runs in a guest: Linux arm64 under QEMU for kernel work, a container for builds, and a macOS guest VM for XNU, kexts and anything that needs SIP off. The host is never touched. Read Lab environment: VMs, containers, snapshots before Phase 0.

阶段

Phases

  1. 0Foundations
    C 系统编程、ARM64 基础（Apple Silicon）、工具链、在 QEMU 里编译并启动 LinuxC systems programming, ARM64 basics (Apple Silicon), toolchain, build and boot Linux in QEMU
  2. 1Boot & Processes
    boot chain、进程/线程模型、上下文切换、调度（CFS/EEVDF ↔ Mach scheduler）Boot chain, process/thread model, context switch, scheduling (CFS/EEVDF ↔ Mach scheduler)
  3. 2Memory
    虚拟内存、ARM64 页表、缺页路径、分配器（buddy/slab ↔ Mach VM/zalloc）Virtual memory, ARM64 page tables, the page-fault path, allocators (buddy/slab ↔ Mach VM/zalloc)
  4. 3Concurrency & IPC
    spinlock/mutex/RCU、内存序；Mach port 与消息Spinlocks, mutexes, RCU, memory ordering; Mach ports and messages
  5. 4Syscalls, VFS & Filesystems
    系统调用入口、VFS 层次、ext4 ↔ APFS、块 I/OSyscall entry, the VFS layers, ext4 ↔ APFS, block I/O
  6. 5Device Drivers
    Linux driver model / devicetree ↔ IOKit / DriverKit，中断与 DMALinux driver model / devicetree ↔ IOKit / DriverKit, interrupts and DMA
  7. 6Debugging & Tooling
    ftrace/perf/kgdb/crash ↔ lldb+KDP/dtrace/panic log；读内核源码的方法ftrace/perf/kgdb/crash ↔ lldb+KDP/dtrace/panic logs; how to read kernel source
  8. 7Security & Hardening
    KASLR、PAN/PXN、PAC、PPL/SPTM、sandbox、code signingKASLR, PAN/PXN, PAC, PPL/SPTM, sandbox, code signing
  9. 8XNU & the Apple Track
    编译 XNU、Darwin 内部阅读计划、作品项目（Linux module + DriverKit driver）、Apple 面试环节Build XNU, a Darwin internals reading plan, a portfolio project (Linux module + DriverKit driver), the Apple interview loop
