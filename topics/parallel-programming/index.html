Parallel Programming

目标：在你面前这台多核机器上写出正确、可测量地更快的共享内存并行程序——从线程和锁，到让它们正确的内存模型，到无锁结构、OpenMP 和 NEON——每一步都用数字说话，并且看得见硬件和内核在底下做什么。实验直接在 Mac 上做：这里测的就是这台机器。

Goal: write correct, measurably faster shared-memory parallel programs on the multicore machine in front of you, from threads and locks, to the memory model that makes them correct, to lock-free structures, OpenMP and NEON, with numbers at every step and the hardware and the kernel beneath it in view. The labs run on the Mac itself: the machine being measured is the one you are sitting at.

读者画像：会 C、看得懂 C++；做过或正在做 Kernel Engineering。每个 phase 大约 1–2 周（每天 1–2 小时）。实验机器是 Apple Silicon Mac（本页的数字来自一台 M5：4 个性能核 + 6 个能效核，128 字节缓存行）；先看「实验环境」。
Reader: knows C, can read C++; has done or is doing Kernel Engineering. Each phase is about 1–2 weeks at 1–2 hours a day. The lab machine is an Apple Silicon Mac (the numbers on these pages come from an M5: 4 performance plus 6 efficiency cores, 128-byte cache lines); start with the lab environment page.
